**Memora Engine** — JavaScript-ядро для ролевых чатов с языковыми моделями. Оно собирает контекст хода из истории, правил игрока, памяти и состояния сцены. Один и тот же файл работает в Node.js и браузере без внешних зависимостей или API-ключей.

> Статус: локальная сборка для проверки. Подготовительная сборка; публичного релиза на GitHub или npm нет. Ядро распространяется по [лицензии с атрибуцией](LICENSE).

## Быстрый старт

Распакуйте архив и запустите из его корня:

```sh
node examples/first-scene.cjs
node --test core.test.cjs
```

```js
const { buildPersonalContext } = require('./roleplay-engine.js');

const context = buildPersonalContext({
  history: [
    { role: 'user', createdAt: 1, content: 'Запомни: пиши от третьего лица' },
  ],
});

console.log(context);
```

`context` — текст для подстановки в запрос к модели, **не ответ персонажа**. Запрос отправляет ваше приложение. В Node.js также доступен именованный импорт: `import { buildPersonalContext } from './roleplay-engine.js';`.

В браузере загрузите ядро **до** кода приложения:

```html
<script src="./roleplay-engine.js"></script>
<script>
  const context = window.MemoraRoleplayEngine.buildPersonalContext({ history: [] });
  console.log(context);
</script>
```

## Что в ядре, а что вне его

| В ядре | В приложении |
|---|---|
| Явные правила игрока и разовые указания | Интерфейс, сессии, сохранение и синхронизация |
| Отбор фактов по активным репликам и список исключений | Фоновый запуск анализа и проверка актуальности ответа перед записью |
| Состояние сцены: место, участники, незакрытые события | Авторизация, выбор провайдера, HTTP и потоковая передача |
| Контекст группового ответа и решение о продвижении очереди | Определение адресата и фактическое продвижение очереди |
| Подготовка запросов анализа и разбор результатов | Вызов самой языковой модели |

В группе ядро задаёт, кто должен отвечать, но не переносит туда личную память и не изолирует секреты по героям автоматически. Формулировки контекста по умолчанию русскоязычные. Ядро не гарантирует, что модель выполнит каждую инструкцию.
