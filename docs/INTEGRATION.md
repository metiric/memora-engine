# Интеграция Memora Engine

```text
Приложение → история активной ветки, правила, факты, журнал сцены
           → Memora Engine → текст контекста
           → адаптер приложения → модель → поток ответа
           → фоновый анализ → разбор в Memora Engine
           → проверка источников и сохранение в приложении
```

1. Подготовьте данные активной ветки. Для личного диалога вызовите `buildPersonalContext`; для группового — `buildGroupContext` с уже найденным адресатом и выбранным участником.
2. Соедините контекст с каноном персонажа и отправьте через свой адаптер. Отдельно контролируйте токен-бюджет, отказ провайдера, завершение потока и доступ к приватному канону.
3. После завершённого ответа возьмите `recentFactMessages(history)`. Если данных достаточно, сформируйте запрос анализа и разберите результат. Перед сохранением проверьте, что сессия и версии реплик не изменились. Не записывайте результат для удалённого чата, старого варианта или прерванного ответа.
4. При правке или свайпе передайте новую активную историю. Для новой ветки переносите только данные, допустимые на момент развилки. Хранение, исключения, повторные попытки и выбор модели остаются обязанностью приложения.

## Патч для сайта Memora

[`integration/integration-v2.patch`](../integration/integration-v2.patch) рассчитан на точный снимок Memora после исправления потоковой передачи (`20261122-engine-audit-1`) и соответствующие тестовые фикстуры. Это не универсальный установщик; не применяйте его поверх другого снимка, если проверка не проходит. В корне совместимой копии:

```sh
git apply --check --whitespace=error-all /path/to/integration-v2.patch
git apply /path/to/integration-v2.patch
npm run test:engine
npm run test:chat-workspace
npm run test:group
```

Патч подключает общий файл к Node.js и обеим страницам чата; HTML загружает его раньше адаптера. Исправление в серверном адаптере сохраняет личную историю при объединении в пределах лимита байтов вместо прежних 80 сообщений. Уже отброшенные реплики патч не восстанавливает. Групповой лимит не меняется. Патч не включает групповой маршрут на публичном сайте.

## Проверенная сборка

В предыдущем локальном прогоне сохранены и прочитаны 102 синтетических сообщения через HTTP, проверены правило из начала истории, поиск и удаление в «Недавних», а также порядок резервирования на мок-провайдерах. Реальные ключи, пользовательские данные и скрипты деплоя не входят в архив. Перед публичным релизом нужно определить лицензию и проверить публикуемое дерево и историю на секреты.
